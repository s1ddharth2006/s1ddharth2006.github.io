A Netflix-inspired, content-based movie recommendation system. Harnesses traditional NLP (TF-IDF vectorization) and high-dimensional cosine similarity across 4,800+ films to compute instant, explainable similarity scores and deliver real-time cinematic recommendations through a responsive Streamlit UI integrated with the TMDB API.

P/003
Machine Learning PyMuPDF Scikit-Learn Classification Semantic Search

Documind: Document Intelligence

An end-to-end AI/ML document intelligence platform built without external LLM APIs. Extracts text, metadata, and layout from multi-page PDFs via PyMuPDF, computes lexical statistics, executes 6-category supervised classification via a scikit-learn pipeline, and performs in-document TF-IDF vector semantic search with page-level highlighting.

GitHub Repo
